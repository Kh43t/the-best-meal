# The Best Meal You Ever Had

Entry for make.fun competition `u-pangg7-the-best-meal-you-ever-had-a3ac0f85`.

`main.ts` writes a single sentence (128 characters) about the best meal I ever
had to `/output/entry.txt` (or to `MAKEFUN_OUTPUT_DIR` when set). Run it with:

```sh
node main.ts
```

The sentence: "My grandmother's rendang, eaten cold from the pot at midnight
with sticky rice and my fingers, while she pretended not to notice."
